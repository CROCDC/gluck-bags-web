de line-art enmarcadas**. Las mejores tomas de producto usan este fondo. Las placas con título serif
(TOTE, MINI BAG, BUCKET BAG, Sobre) son piezas de marketing ya diseñadas → sirven como banners.

## ✅ Optimizaciones aplicadas
- **Loops de hero** (muteados, recortados ≤10s) → [`app/static/video/loops/`](../app/static/video/loops/): `relanzamiento-loop`, `crossbody-rosa-loop`, `bucket-bag-loop`, `cuero-loop` (mp4 + webm).
- **Thumbnails cuadrados** 600×600 (center-crop) para grilla → [`app/static/img/thumbs/`](../app/static/img/thumbs/) (13).
- **`.webp`** de las 33 imágenes (~30% más livianas que el jpg) — conviven con el `.jpg` para `<picture>`.
- **`.webm`** (VP9) de los 9 videos — conviven con el `.mp4` para `<source>` con fallback.

### Cómo usarlos en las plantillas (patrón recomendado)
```html
<!-- imagen con webp + fallback jpg -->
<picture>
  <source srcset="{{ url_for('static', filename='img/productos/tote-cognac-01.webp') }}" type="image/webp">
  <img src="{{ url_for('static', filename='img/productos/tote-cognac-01.jpg') }}" alt="Tote cognac">
</picture>

<!-- loop de hero muteado con autoplay -->
<video autoplay muted loop playsinline poster="{{ url_for('static', filename='img/video-posters/relanzamiento-gluck-2026.jpg') }}">
  <source src="{{ url_for('static', filename='video/loops/relanzamiento-loop.webm') }}" type="video/webm">
  <source src="{{ url_for('static', filename='video/loops/relanzamiento-loop.mp4') }}" type="video/mp4">
</video>
```
